# Performance benchmark tests

Write BATS performance tests measuring command execution time at scale (100 tickets). 7 tests in 1 file.

## Design

File: test/30-perf.bats
Uses setup_file with BATS_FILE_TMPDIR and fixture_at_scale(100) to amortize setup.
Calibration step: measure baseline with 10 tickets, then assert 100-ticket ops complete within relative threshold.
Tests: ls, ready, blocked, query, dep tree (20-deep chain), stats at 100 tickets.
PERF_MULTIPLIER env var for CI tolerance. Advisory failures unless PERF_STRICT=1.
Relative thresholds test algorithmic scaling, not absolute machine speed.

## Acceptance Criteria

All 7 perf tests pass locally. Graceful advisory failure in CI. Thresholds catch O(n^2) regressions while tolerating normal variance.
