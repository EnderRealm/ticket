# BATS test infrastructure

Build comprehensive BATS-based test suite to verify tk against its full specification (docs/CLAUDE-SPECIFICATION.md). ~243 test cases across 26 test files covering all commands, data model, lifecycle rules, output formats, error handling, and performance.

## Design

Framework: BATS (bats-core v1.8.0+) with bats-assert, bats-support, bats-file as git submodules.
Isolation: Per-test via BATS_TEST_TMPDIR (fresh TICKETS_DIR per test, auto-cleaned).
Helpers: test/helpers/common.bash (TK path, setup, custom assertions) + test/helpers/fixtures.bash (create_ticket, read_field, scenarios).
Test files: test/NN-topic.bats numbered by spec section.
CI: GitHub Actions on ubuntu+macos with submodules:true.

## Acceptance Criteria

All non-skipped tests pass on macOS and Linux. Suite covers every command, every flag, lifecycle rules, output formats, error categories, and performance scaling.
